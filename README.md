# AtlasA1-uboot

U-Boot, TF-A, SPL, and LPDDR4x boot sources for the T736 Aurora/AtlasA1 board.

The board uses a fixed LPDDR4x training input supplied outside this public repository. The source tree documents the expected interface and checks, but does not redistribute the authorised vendor training binary. Build and payload instructions are in AtlasA1-build.
